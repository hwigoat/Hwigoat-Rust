## 다중 창 지원 | Multi-Window Experience

### 신규 기능
- 상단 새 창 버튼과 브라우저 UI에서 Ctrl + N으로 독립적인 Windows 창을 엽니다.
- 데스크톱 또는 시작 메뉴에서 다시 실행하면 기존 프로세스에 새 창을 요청합니다.
- 창마다 탭, 주소창, 크기 및 위치를 독립적으로 조작할 수 있습니다. 최대 12개 창을 지원합니다.
- 일반 창은 동일한 브라우저 프로필을 사용하며 설정, 북마크, 방문 기록을 공유하도록 구성했습니다.
- 창별 일반 탭 세션을 저장하고 복원하도록 구성했습니다. 시크릿 탭은 복원 대상에서 제외합니다.

### 개선 사항
- 마지막 탭을 닫으면 해당 창만 닫습니다. 다른 창은 유지됩니다.
- 모든 창이 종료된 뒤에만 자동 업데이트를 적용합니다.
- 창별 이벤트를 분리하고 사용자 데이터의 저장 작업은 하나의 저장기로 통합했습니다.

### 설치 및 업데이트
Windows x64용 `Hwigoat_Rust_Setup_v1.0.6_x64.exe`를 사용합니다. 자동 업데이트 기능이 있는 버전에서는 업데이트 확인 후 모든 창을 정상 종료하고 다시 실행하세요.

### 검증 및 제한
- Windows CI 빌드·단위 테스트·UI 회귀 테스트·서명 성공 후에만 릴리스 초안이 생성됩니다.
- 실제 Windows에서 다중 창의 렌더링, 공유 로그인, 세션 복원, 종료 후 업데이트 적용 검증이 필요합니다.
- 브라우저 UI에 초점이 있을 때 Ctrl + N을 지원합니다. 웹페이지 내부 단축키 및 별도 시크릿 창은 이번 버전의 보장 범위가 아닙니다.
- WebView2 로그인 제한 및 Authenticode 미서명 상태는 이전 버전과 동일합니다.
