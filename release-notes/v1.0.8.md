## 탭 합치기 및 가시성 개선 | Tab Docking & Visual Clarity

### 신규 기능
- 탭을 다른 Hwigoat Rust 창의 탭 바에 끌어 놓으면 기존 창에 합칩니다.
- 같은 창에서 탭을 드래그해 순서를 변경합니다.
- 드래그 중 대상 탭 바와 삽입 위치에 표시를 제공합니다.
- 마지막 탭을 다른 창으로 옮긴 경우 빈 원래 창만 닫습니다.

### 인터페이스 개선
- 기존 흑백 테마를 유지하며 활성/비활성 탭의 배경 및 글자 대비를 높였습니다.
- 활성 탭의 강조선, 탭 닫기 및 탐색 아이콘 가독성을 개선했습니다.
- 주소창 경계선 및 드래그 안내를 명확하게 표시합니다.

### 안정성 및 업데이트
- 기존 콘텐츠 WebView를 재부착하는 방식으로 이동합니다. 시크릿 탭 속성과 콘텐츠 이벤트 ID를 유지합니다.
- 대상 창이 가득 차거나 재부착에 실패하면 원본 탭을 유지하도록 구성했습니다.
- 기존 서명된 업데이트 및 모든 창 종료 후 적용 정책을 유지합니다.

### 설치 및 검증
Windows x64용 `Hwigoat_Rust_Setup_v1.0.8_x64.exe`를 사용합니다. Windows CI 빌드·단위 테스트·Chromium UI 회귀 테스트·서명 통과 후 릴리스 초안이 생성됩니다. 실제 Windows에서 창 간 마우스 캡처, DPI, WebView 재부착 및 페이지 상태 유지 검증은 별도로 필요합니다. 드래그를 놓을 때 이동이 확정되며, 드래그 중 별도 실제 창이 마우스를 따라오는 기능은 이번 버전 범위에 포함하지 않습니다. 기존 WebView2 인증 제한 및 Authenticode 미서명 상태는 유지됩니다.
