## 부드러운 탭 조작 | Fluid Motion

### 개선 사항
- 탭 바 내부에서 탭 미리보기가 마우스에 맞춰 움직입니다. requestAnimationFrame과 translate3d로 화면 프레임에 맞춰 표시하며 실제 탭의 도킹 좌표는 유지합니다.
- 네이티브 미리보기의 마우스 추적 목표 간격을 16ms에서 8ms로 줄였습니다. 실제 갱신 빈도는 Windows의 타이머와 디스플레이 환경에 따라 달라집니다.
- 미리보기의 커서 기준점을 드래그 시작 시 고정하여 화면 가장자리에서 반대편으로 갑자기 이동하지 않도록 구성했습니다. 가장자리에서는 일부 미리보기가 화면 밖에 위치할 수 있습니다.
- 같은 창의 삽입 위치가 바뀔 때 도킹 표시를 숨기지 않고 이어서 이동합니다. 도킹 영역을 벗어날 때의 짧은 재표시 지연으로 깜빡임을 줄였습니다.
- 드래그 시작 거리 7px, 정상 클릭 및 Esc 취소를 구분합니다. 드래그 중에만 추적 타이머와 미리보기 요소를 사용합니다.
- 1.1.0 블랙 테마, 기존 WebView 이동, 모든 창 종료 후 서명된 자동 업데이트 정책을 유지합니다.

### 검증 및 제한
- 1.1.0 공개 빌드의 통합 소스에 변경을 적용하여 로컬 Chromium UI 회귀 테스트 및 Python 문법 검사를 통과했습니다.
- Windows CI 빌드 및 서명 통과 후 릴리스 초안이 생성됩니다. 실제 Windows DWM 움직임, 다중 모니터 및 체감 프레임 안정성은 추가 검증이 필요합니다.
- 드래그 중 별도의 네이티브 DWM 미리보기를 사용하며 실제 WebView는 드롭할 때 이동합니다. Chrome의 네이티브 탭 구현과 동일한 방식은 아닙니다.

### 설치
Windows x64용 `Hwigoat_Rust_Setup_v1.1.1_x64.exe`를 사용합니다. 자동 업데이트는 모든 창의 정상 종료 후 적용하도록 설계되어 있습니다. Windows Authenticode 미서명 및 WebView2 인증 제한은 이전 버전과 동일합니다.
