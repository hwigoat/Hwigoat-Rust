## 브라우저 사용성 개선 | Browser Experience Update

일상적인 탐색 동작, 시크릿 탭, 자동 업데이트의 편의성을 개선한 공개 베타입니다.

### 신규 기능
- 상단 시크릿 탭 버튼과 브라우저 UI에서 Ctrl + Shift + N 단축키.
- 시크릿 탭의 전용 표시 및 WebView2 InPrivate 활성 여부 확인.
- 실행 시 및 실행 중 30분 간격 백그라운드 업데이트 확인.

### 개선 사항
- 마지막 탭을 닫으면 새 탭을 생성하지 않고 브라우저를 정상 종료합니다.
- 설정에서 뒤로가기, Esc, Alt + 왼쪽 화살표로 기존 웹페이지에 복귀합니다.
- 설정에서 업데이트 상태를 주기적으로 갱신합니다.
- 다운로드 중 정상 종료 시 업데이트 적용 요청이 누락되는 경쟁 조건을 줄였습니다.
- GitHub 빌드 성공 후 서명된 릴리스 초안을 자동 생성합니다.

### 시크릿 모드 안내
별도 창이 아닌 시크릿 탭 방식입니다. 일반 프로필과 분리된 InPrivate 세션을 사용하도록 구현했으며, 다운로드한 파일은 남을 수 있습니다. 시크릿 모드는 웹사이트나 네트워크 관리자로부터 사용자를 익명화하지 않습니다. 실제 Windows에서 격리 동작을 추가 검증해야 합니다.

## 설치 및 업데이트

- Windows x64용 `Hwigoat_Rust_Setup_v1.0.5_x64.exe`를 Assets에서 다운로드해 실행하세요. Rust나 C++ 개발 도구는 필요하지 않습니다.
- 기존 설치에 덮어쓰는 방식이며 일반 사용자 프로필을 유지하도록 설계되었습니다. 자동 업데이트 지원 버전은 브라우저 설정의 업데이트 상태를 확인한 뒤 정상 종료하고 다시 실행하세요.
- `SHA256.txt`는 파일 무결성 확인용이며, `update.json`과 `update.sig`는 자동 업데이트 에이전트용입니다.

## 검증 및 알려진 제한

- Windows CI의 Rust 컴파일, 단위 테스트, Chromium UI 회귀 테스트, 설치기 빌드 및 Ed25519 업데이트 매니페스트 서명 성공.
- 실제 Windows 설치·업데이트 전 과정 및 Claude 등 외부 사이트의 로그인 성공은 별도 실환경 검증이 필요합니다.
- 설치 EXE는 Windows Authenticode 미서명입니다. Ed25519 업데이트 서명은 Authenticode와 별개입니다.
- 일부 OAuth 제공자는 WebView2 같은 임베디드 브라우저 로그인을 제한할 수 있습니다. 기본 브라우저에서 로그인하더라도 세션은 자동 이전되지 않습니다.
