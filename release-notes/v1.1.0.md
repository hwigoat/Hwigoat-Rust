## 정밀 조작 및 안정화 | Precision & Stability

1.1.0은 탭 이동 조작감, 가시성과 안정성을 개선한 공개 베타 후보입니다.

### 탭 이동
- 탭을 끌어내면 DWM으로 활성 브라우저 화면을 보여주는 네이티브 Windows 미리보기 창이 마우스를 실시간으로 따라갑니다.
- 탭 바의 빈 공간 및 버튼 사이까지 도킹 영역을 확대하고 상하 여유를 제공합니다. 유효한 대상에서는 미리보기 대신 삽입 위치를 강조합니다.
- 마우스를 놓으면 기존 WebView를 이동합니다. 시크릿 속성, 이벤트 ID 및 세션을 유지하도록 구성했습니다.
- 드래그 취소, 마우스 캡처 손실, 중복 종료 요청 및 이동 실패를 안전하게 처리합니다. DWM을 사용할 수 없으면 기존 분리/합치기 동작으로 대체합니다.

### 블랙 테마
- 프레임 #000000, 도구 모음 #101010, 주소창 #050505, 활성 탭 #202020.
- 글자 대비, 활성 탭 강조 및 드롭 표시 개선. 라이트 테마 유지.

### 안정화 및 개발
- 드래그 중에만 16ms 간격의 네이티브 마우스 상태 확인을 사용합니다.
- 마지막 창 종료 후 자동 업데이트 정책을 유지하고 드래그 중 자동 탭 해제를 보류합니다.
- 화면 밖 창 위치 방지, 생성 Python 문법 사전 검사, Chromium 회귀 테스트를 Rust 컴파일보다 먼저 수행합니다.
- 빌드 결과에 생성된 Rust/HTML/Go 소스 아카이브를 추가하여 후속 소스 통합 및 검토를 지원합니다.

### 설치 및 검증
Windows x64용 `Hwigoat_Rust_Setup_v1.1.0_x64.exe`를 사용합니다. Windows CI와 서명 통과 후 초안이 생성됩니다. 네이티브 미리보기는 실제 탐색 창과 별개의 DWM 미리보기이며, 원본 탭은 드롭할 때만 이동합니다. DWM·실제 Windows 마우스 캡처·다중 모니터·WebView 재부착 및 자동 패치는 실환경 검증이 필요합니다. 기존 WebView2 로그인 제한 및 Authenticode 미서명 상태는 유지됩니다.
