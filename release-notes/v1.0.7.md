## 탭 드래그 분리 | Tab Tear-Off

### 신규 기능
- 탭 제목을 누른 채 탭 바 밖으로 드래그하고 놓으면 새 Windows 창으로 분리합니다.
- 이미 로드된 탭의 WebView를 재생성하지 않고 새 창에 재부착합니다. 페이지 상태, 탐색 기록 및 인증 세션 유지를 목표로 합니다.
- 하나의 탭만 남은 창은 추가 창을 만들지 않고 이동합니다.
- 드래그 도중 탭 바 안으로 돌아오거나 Esc를 누르면 분리를 취소합니다.

### 안정성 개선
- 창마다 고유 탭 ID 범위를 사용하며 이동 후에도 제목, 탐색, 팝업, 다운로드 이벤트를 현재 소유 창으로 전달합니다.
- 새 창 생성 또는 WebView 재부착 실패 시 원래 탭을 유지하도록 처리했습니다.
- 기존 최대 12개 창 제한과 마지막 창 종료 후 자동 업데이트 정책을 유지합니다.

### 설치 및 업데이트
Windows x64용 `Hwigoat_Rust_Setup_v1.0.7_x64.exe`를 사용합니다. 기존 사용자는 업데이트 확인 후 모든 창을 정상 종료하고 다시 실행하세요.

### 검증 및 제한
- Windows CI 빌드·단위 테스트·Chromium UI 회귀 테스트·서명 성공 후 릴리스 초안이 생성됩니다.
- 실제 Windows에서 창 외부 드래그, WebView 재부착, 입력 및 미디어 상태 유지, 모니터 간 DPI 동작을 추가 검증해야 합니다.
- 드래그를 놓을 때 분리되며 Chrome처럼 이동 중 실시간 창 미리보기 또는 다른 기존 창에 탭을 합치는 기능은 이번 버전의 범위가 아닙니다.
- WebView2 인증 제한 및 Authenticode 미서명 상태는 이전 버전과 동일합니다.
