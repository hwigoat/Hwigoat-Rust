## 자동 업데이트의 시작 | Auto Update & Login Compatibility

자동 업데이트 기반을 도입하고 웹사이트의 인증 호환성을 개선한 공개 베타입니다.

### 신규 기능
- 공식 GitHub 릴리스 확인, 백그라운드 다운로드, 정상 종료 후 패치 적용.
- Ed25519 서명 및 SHA-256 검증, 하위 버전 설치 방지.
- 설정의 자동 업데이트 켜기·끄기, 수동 확인 및 상태 확인.

### 개선 사항
- 주요 인증 사이트의 로그인 팝업과 리디렉션 처리 개선.
- 주요 인증 사이트의 비활성 탭 자동 해제 제한.
- 기본 브라우저에서 Claude를 열 수 있는 메뉴 추가.

### 중요
자동 업데이트를 사용하려면 기존 사용자는 공개키가 내장된 1.0.3 이상을 한 번 수동 설치해야 합니다.

## 설치 및 업데이트

- Windows x64용 `Hwigoat_Rust_Setup_v1.0.3_x64.exe`를 Assets에서 다운로드해 실행하세요. Rust나 C++ 개발 도구는 필요하지 않습니다.
- 기존 설치에 덮어쓰는 방식이며 일반 사용자 프로필을 유지하도록 설계되었습니다. 자동 업데이트 지원 버전은 브라우저 설정의 업데이트 상태를 확인한 뒤 정상 종료하고 다시 실행하세요.
- `SHA256.txt`는 파일 무결성 확인용이며, `update.json`과 `update.sig`는 자동 업데이트 에이전트용입니다.

## 검증 및 알려진 제한

- Windows CI의 Rust 컴파일, 단위 테스트, Chromium UI 회귀 테스트, 설치기 빌드 및 Ed25519 업데이트 매니페스트 서명 성공.
- 실제 Windows 설치·업데이트 전 과정 및 Claude 등 외부 사이트의 로그인 성공은 별도 실환경 검증이 필요합니다.
- 설치 EXE는 Windows Authenticode 미서명입니다. Ed25519 업데이트 서명은 Authenticode와 별개입니다.
- 일부 OAuth 제공자는 WebView2 같은 임베디드 브라우저 로그인을 제한할 수 있습니다. 기본 브라우저에서 로그인하더라도 세션은 자동 이전되지 않습니다.
